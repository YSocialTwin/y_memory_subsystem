# Features

## Shared package features

- A single engine signature across backends
- Typed request and response contracts
- Memory capability advertisement
- Shared prompt-safety and affect policies
- Replacement-friendly runtime adapter boundary

## Read path features

- Reply context assembly
- Browse/thread context assembly
- Post-style guidance context
- Relationship signals

## Write path features

- Comment event recording
- Vote event recording
- Root post recording
- Periodic maintenance hooks

## Hybrid semantic features

- Social-card metrics
- Thread-card memory
- Community digest
- Reflection items
- High-affect recall pack construction
- Vote-signal-only suppression for prompt-visible memory

## Simple recent features

- Deterministic pair history
- Deterministic thread history
- Lightweight relationship counters
- Decay via maintenance tick

## Not included in the package

- Client-specific `Agent` classes
- Direct server persistence APIs for either client
- Prompt catalogs for all non-memory actions
- Recommendation-system logic
